- 🏝️ **Full-Width Alternating Luxury Design System**: Alternating warm ivory (`#f8f7f2`) and deep olive (`#23271a`) color rhythm built with custom Tailwind CSS variables.
- 🛰️ **Interactive Satellite HUD Locations Map**: Real-time interactive map with island region filters (*Phuket & Koh Samui*), price tags, radar pulse rings, and hover tooltips.
- 🤖 **AI Senior Concierge**: Built-in AI concierge matching buyers with carbon-neutral residences based on budget and location preferences.
- 📝 **Bespoke Quote & Booking Engine**: Integrated lead registration and property viewing scheduler with local storage persistence.

## 🚀 Getting Started Locally

### Prerequisites
- **Node.js**: `v18.0.0` or higher
- **npm** or **pnpm**

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/rajulbusiness007-star/pigma-sustainable-luxury.git
   cd pigma-sustainable-luxury
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set Environment Variables**:
   Create a `.env.local` file in the root directory:
   ```env
   GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
   APP_URL="http://localhost:3001"
   ```

4. **Launch Development Server**:
   ```bash
   npm run dev
   ```

   Open [http://localhost:3001](http://localhost:3001) in your browser.
